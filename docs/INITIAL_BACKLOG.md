# RAFID — مهام بداية التنفيذ

> هذه قائمة البنية الأصلية الأكبر. استُبدلت في مهلة التسليم بـ[نطاق اليومين](MVP_48H.md)؛ ليست قائمة حالة التطبيق الحالي.

مرجع النطاق والقبول: [Implementation Plan](IMPLEMENTATION_PLAN.md). جميع المهام أدناه **غير منفذة**. الترتيب يعكس التبعيات، ويمكن تفصيله إلى Issues عند بدء التطوير؛ لا توجد Issues منشأة بهذا التسليم.

| ID | المهمة | يعتمد على | دليل الإنجاز |
|---|---|---|---|
| FND-01 | تسجيل ADR للبنية والنسخ المتوافقة وقرارات السياسة | — | اختيار Node والحزم ومدير الحزم وقفل نسخ، والعملة/المهل/الرسوم كقرارات واضحة أو إعدادات تجريبية |
| FND-02 | إنشاء workspace لـweb وapi وpackages | FND-01 | تثبيت من clone نظيف وبناء قابل للتكرار، README بأوامر فعلية |
| FND-03 | PostgreSQL محلي ومهاجرة أولى وseed | FND-02 | إنشاء قاعدة فارغة وترحيلها وبيانات تجريبية قابلة للإعادة دون أسرار ثابتة للإنتاج |
| FND-04 | إعداد configuration وhealth وlogs وأخطاء وعقود API | FND-03 | فشل واضح عند نقص إعداد مطلوب، health يعكس جاهزية DB، OpenAPI محدث |
| FND-05 | مصفوفة صلاحيات وتصميم جلسات ونطاق المنظمات | FND-01 | اختبارات تصميم لعزل المورد والسائق والمحل وموظف العمليات، وسياسة منع الحساب الموقوف |
| FND-06 | هيكل واجهات عربية RTL قابل للجوال | FND-02 | تخطيطات الأدوار ومكونات أخطاء/تحميل وتنقل بلوحة المفاتيح دون بيانات تجارية وهمية توحي بتنفيذ |
| FND-07 | إعداد CI ووحدات وتكامل مع قاعدة مؤقتة | FND-03، FND-04 | build وlint وtypecheck واختبار migration واتصال DB؛ اختبار وظيفة محمية عند تنفيذ الهوية |

| IDN-01 | دخول وخروج وانتهاء الجلسة وتقييد المحاولات | FND-05، FND-07 | اختبارات دخول وفشل وخروج وتعطيل حساب وعدم تجاوز الدور |
| ORG-01 | اعتماد المورد وإدارة متجره وتسجيل محل وعنوان | IDN-01 | سيناريو مدير يعتمد المورد، ومحل يضيف عنوانه؛ منع تسرب بيانات الجهات |
| CAT-01 | دليل موحد وتصنيفات وطلب إضافة منتج | ORG-01 | اختلاف العبوة ينشئ هوية مختلفة ومراجعة الإدارة تربط المنتج الصحيح |
