# نطاق تسليم النسخة الأولية خلال يومين

**بدأ:** 2026-10-31. **هدف المستخدم:** نسخة أولية قابلة للتسليم بتاريخ 2026-11-02 بتوقيت دمشق.

حل هذا النطاق محل تقدير 10–15 أسبوعًا للمرحلة الأولى. التغيير سببه مهلة التسليم؛ لا يعني تنفيذ كل خارطة التطوير في يومين. يشمل التسليم الشفرة على GitHub وتشغيلًا محليًا ودليل نشر. الاستضافة العامة تحتاج خادمًا ونطاقًا فعليين.

## اختيار التنفيذ

تطبيق ويب عربي واحد متجاوب للأدوار الأربعة، وخادم Node.js 24، وSQLite بمعاملات على خادم واحد. لا حزم خارجية. قاعدة البيانات على قرص دائم، ومخططها يُنشأ ويُحدّث بإضافات تلقائية. اختبارات HTTP تغطي القواعد والدورة التجارية. PostgreSQL وإطار الواجهات الأكبر يعودان عند التوسع بعد هذه النسخة.

## حدود مقصودة لهذه النسخة

- منطقة خدمة واحدة ومركبة واحدة لكل سائق، وجدول واحد وفترة واحدة لكل مورد. لا خرائط مضلعات أو مسافة؛ تطابق المنطقة باسمها الموحد.
- الإسناد يدوي؛ تستلم بضائع جميع طلبات الرحلة قبل بدء التوزيع. يختار السائق ترتيب الزيارات ضمن ذلك، دون تحسين آلي أو ETA حي.
- السعة مجموع حمولة الرحلة كحد محافظ، دون إعادة تعبئة بين المحطات أو حساب حجم. الوزن صفر يعني مجهولًا ويحتاج مراجعة الإدارة؛ لا ادعاء بدقة وزن مجهول.
- العروض عامة أو لمحل واحد، والاستفادة ببند طلب؛ لا مجموعات أو شرائح كمية أو حملات.
- التوصيات تفحص حتى 512 توزيعًا وعشرة منتجات مختلفة؛ تفصح عن سقف البحث. مرجع التوفير السلة الحالية ورسومها.
- القبول على السعر المحفوظ أو الرفض؛ لا تعديل أو استبدال دون طلب جديد. المخزون المعروض بعد الحجز. الحجز pending ينتهي بعد 24 ساعة.
- الإلغاء الذاتي قبل قبول المورد فقط. تعويضات وإرجاعات ما بعد التسليم كشكاوى بقرار موثق، دون محفظة.
- رمز التسليم بحساب المحل وليس SMS. كلمة مرور للحساب، دون تحقق هاتف أو استعادة آلية. إنشاء المورد والسائق يدوي.
- تقارير أساسية، دون BI أو ذمم أو عمولات آلية. تتبع بتحديث الشاشة؛ لا إشعارات خارجية أو دفع إلكتروني أو GPS أو وضع دون اتصال أو Native.
- خادم واحد وSQLite على قرص محلي دائم؛ لا replicas أو ملف DB مشترك شبكيًا. الانتقال لقاعدة خادمية يسبق التوسع.

## بوابة الاكتمال

نجاح `npm run check` و`npm test`، ومراجعة الواجهة، وتنفيذ سيناريو طلب متعدد الموردين وتجهيز وإسناد وتسليم بإثبات، مع حفظ البيانات والشكاوى. توثيق الحدود ودليل التشغيل جزء من التسليم. لا يعني هذا اكتمال الاستضافة العامة أو الاتفاقات التجارية أو بيانات الموردين الحقيقيين.

بعد اجتياز البوابة نتوقف عن إضافة الميزات كما طلب المستخدم؛ التوسع يحتاج طلبًا جديدًا.
