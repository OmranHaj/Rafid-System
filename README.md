# رافد | RAFID

نسخة أولية لتجارة الجملة في دمشق: تطبيق ويب عربي متجاوب للمحل والمورد والإدارة والسائق، وخادم وقاعدة بيانات دائمة.

## تشغيل العرض المحلي

يلزم **Node.js 24 أو أحدث**. لا توجد حزم خارجية أو عملية تثبيت.

```powershell
npm run demo
```

افتح [رافد المحلي](http://127.0.0.1:3000) واختر الدور من شاشة الدخول. كلمة مرور **العرض المحلي فقط**: `RafidDemo2026!`.

| الدور | حساب العرض |
|---|---|
| الإدارة | admin@rafid.local |
| المحل | merchant@rafid.local |
| المورد الأول | supplier@rafid.local |
| المورد الثاني | supplier2@rafid.local |
| سائق المورد الأول | driver@rafid.local |
| سائق رافد | platform@rafid.local |

البيانات تشمل موردين وستة منتجات وأسعارًا مختلفة وعرضًا خاصًا بالمحل، وتُحفظ في `data/rafid.sqlite` بعد إعادة التشغيل. حسابات العرض لا تنشأ خارج DEMO_MODE؛ لا تنشر قاعدة العرض على الإنترنت.

## الميزات المنفذة

- تسجيل محل ودخول وصلاحيات وعزل بيانات الجهات.
- اعتماد مورد ودليل منتجات بمواصفات عبوة وأسعار ومخزون وحدود وعروض عامة وخاصة.
- مقارنة وسلة متعددة الموردين ورسوم ومواعيد مستقلة وتوصيات وتوفير يشمل التوصيل.
- طلب رئيسي وفرعي لكل مورد وحجز ذري ومنع تكرار التأكيد.
- قبول ورفض وتجهيز وإلغاء قبل القبول وانتهاء حجز بعد 24 ساعة.
- أيام خدمة وإغلاق طلبات الغد وسعة يومية بتوقيت دمشق.
- توصيل المورد أو رافد ورحلات متعددة الطلبات وفحص الجهة والمنطقة والوزن.
- قبول السائق وتتبع الحالات ورمز تسليم للمحل فقط وتحصيل وتأكيد استلام.
- تعذر وإعادة محاولة وشكاوى ومعالجة وتقييمات وتقارير وسجل تدقيق.

التتبع بتحديث الحالة والشاشة. manifest للتثبيت بالمتصفحات الداعمة؛ لا طلب أو تسليم دون اتصال.

## التحقق

```powershell
npm run check
npm test
```

اختبارات HTTP وقاعدة مؤقتة تغطي الدورة والصلاحيات والتزامن والسعر والرموز والتوصيات والمواعيد واستمرار البيانات.

## تشغيل خاص ونشر

```powershell
Copy-Item .env.example .env
# عدّل .env: كلمة مرور المدير، PUBLIC_ORIGIN وDB_PATH جديد
node --env-file=.env server.js
```

حساب المدير `admin@rafid.local`، وكلمة مروره من ADMIN_PASSWORD عند أول تشغيل فقط. ابدأ بقاعدة فارغة خارج العرض. ملفات Docker وCompose وCI مرفقة. اقرأ [دليل التشغيل](docs/PILOT_RUNBOOK.md) قبل استقبال طلبات فعلية. لم يُنشر التطبيق على استضافة عامة.

## الحالة الحالية

أصبح المستودع يحتوي تطبيقًا قابلًا للتشغيل والاختبار. مهلة اليومين اختصرت التنفيذ إلى Node.js وSQLite على خادم واحد بدل البنية الأكبر المقترحة في الخطة السابقة. الحدود والميزات المؤجلة موثقة في نطاق مهلة اليومين.

هذه نسخة تجربة ميدانية محدودة؛ لا تعني تنفيذ جميع خارطة التطوير أو الاستضافة العامة. بيانات الموردين وسياسات التشغيل والإيصالات تحتاج إعدادًا فعليًا قبل استقبال عملاء حقيقيين.
